# Animation compatibility correction 0.7.6

This supersedes the 0.7.5 root-offset rebasing. The supplied Max actor-builder source retains animated root translation and marks the translation mask by animation track index; RemovePos removes limb translation channels. A preview skin height is not a replacement animation coordinate system.

Support for all skeletons now builds a temporary reference using the same bind preparation as Actors export. It retains custom bone distances and constructs compatible child-joint offsets in their parent frames. These offsets become Blender pose-location keys for preview; the original mesh and armature rest data remain unchanged. This fixes the supplied custom rig's approximately 172-degree clavicle-frame mismatch without guessed axis snapping. It is not sufficient merely to conjugate rotation curves: that was rejected during visual testing. Source pelvis and Motion translation keys remain unchanged. Source quaternions remain unchanged in game coordinates.

With RemovePos enabled, export discards the fitted limb translations and keeps root/pelvis translation channels and their active mask bits. The animation skeleton uses the fitted convention rather than the preview rig's incompatible axes. Vanilla import mode remains the unretargeted mode. Existing source metadata and Motion track preservation remain supported.

Import original animations again with this version. Already imported 0.7.5 actions retain the older preview conversion. The corrected attack_light3 supplied with this release is a fresh export from the full supplied Spider-Man combat set using the custom rig and Support for all skeletons, with RemovePos enabled. No source files were overwritten.

Validation in Blender 4.5.3: all 34 actions from 09_spiderman_4_combat.igb, on customrigwasted.igb and skin vanilla with env.igb, both import modes (136 animation round trips). Quaternion dot error below 0.00000005; retained translation error below 0.00006 game units. Attack_light3 pelvis motion is present in every combination, with about 1.097 metres range on its largest local component. Limb translation channels are absent after RemovePos. Original rig rest matrices remain unchanged. A custom-rig attack export was reimported onto the vanilla skin and compared with the original at 16 full-skeleton poses (maximum matrix-component difference below 0.001). The custom idle was also rendered and visually inspected; the prior shoulder/arm distortion is absent.

This does not establish universal compatibility with arbitrary bone names or unrelated hierarchies. Matching game bone names and a compatible hierarchy are required; unmatched source tracks other than retained Motion cannot animate missing bones. Root movement stored on Motion is separate from pelvis movement; Transfer Motion to Bip01 is the explicit preview option for folding that travel onto the body. The game itself was not run.
